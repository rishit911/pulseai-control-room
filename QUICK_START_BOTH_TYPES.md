## 📊 Classification Example

### Iris Flower Classification

**1. Load Data**
```
Select: "Iris (Flower Classification)"
Click: "Load Sample Dataset"
```

**2. Configure**
```
Target: species
Features: sepal_length, sepal_width, petal_length, petal_width
```

**3. Train**
```
Model: Random Forest
Parameters: Default
Click: "Train Model"
```

**4. Results**
```
✅ Accuracy: ~95%
✅ 3 classes predicted
✅ Confusion matrix shown
✅ Feature importance displayed
```

## 📈 Regression Example

### House Price Prediction

**1. Load Data**

## 💡 Pro Tips

### For Classification:
- Use when predicting categories
- Check confusion matrix for errors
- Balance your classes if possible
- Try Gradient Boosting for best accuracy

### For Regression:
- Use when predicting numbers
- Check R² score (higher = better)
- Look at residuals plot
- Try Linear Regression first for speed
